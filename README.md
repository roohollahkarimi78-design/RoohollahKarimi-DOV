# Roohollah_Karimi
The folders of "Conventional_Method" and "Proposed_Method" contain all the MATLAB functions required to compute the components of the Helmert deflection of the vertical (DOV) from global geopotential models (GGMs) using the conventional method and the proposed (exact) method. Inside each folder, there is a README file that provides further details about the source code.
The main functions are "Conventional_xi_eta.m" and "Exact_xi_eta.m" that compute the north-south, xi, and east-west, eta, components of the Helmert DOV.
All necessary parameters, including inputs and outputs, are described in detail within each function. 
The computations are based on the EIGEN-6C4 GGM and the GRS80 reference ellipsoid. 
Note: The files "Cnm_EIGEN_6C4_zero_tide.mat" and "Snm_EIGEN_6C4_zero_tide.mat" must be saved in the folders of "Conventional_Method" and "Proposed_Method".
